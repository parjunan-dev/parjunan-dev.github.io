This estimator uses an event-driven Cloud Run model so it is easier to compare with AWS Lambda and Azure Functions. Singapore (`asia-southeast1`) is the baseline region.

Estimated Google charges per month $0.00
Free tier applied

This model reflects event-driven Cloud Run request, CPU, and memory pricing only. It does not include always-on warm instances, jobs, GPUs, or networking-linked charges.

Singapore (`asia-southeast1`) is used as the baseline region. The calculator intentionally excludes idle baseline behavior so the comparison stays closer to AWS Lambda and Azure Functions Consumption.

The free tier is applied directly as free vCPU-seconds, free GiB-seconds, and free requests.
